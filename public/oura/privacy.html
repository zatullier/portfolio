Privacy Policy

Effective November 2, 2026

This policy covers Zach’s Oura Data Export, a personal-use project maintained by Zachary Tullier, and these project information pages.

Current website

These static pages contain no forms, analytics scripts, advertising, or application cookies. They do not request or receive Oura credentials, authorization tokens, or health records. GitHub Pages hosts the site and may process technical request information, such as IP addresses, under GitHub’s privacy statement.

Planned downloader

The downloader is under development. Its intended design is to obtain consent through Oura, retrieve records permitted by that consent, and save exports and necessary authorization credentials on the account owner’s computer. Requested data may include account information, sleep, readiness, activity, heart rate, workouts, tags, sessions, oxygen saturation, and ring configuration where available.

The project is intended for the maintainer’s own account. No project-operated remote health-data storage, sale of data, advertising use, or automatic sharing is planned. This policy must be updated if the implementation changes those practices.

Control and retention

The owner will control local exports and credentials and can delete them from the computer and any backups. Oura authorization can be revoked through Oura’s account controls. Revocation stops future authorized retrieval but does not delete existing exports. Oura’s own processing remains subject to its policies.

Voluntary sharing

Uploading an export to another service, including an AI service, is a separate action governed by that service’s policies. Do not commit exports or authorization credentials to this public repository.

Contact and changes

Contact Zachary Tullier through the GitHub issue tracker for non-sensitive questions. Never include health records or secrets in an issue. This page will be revised when relevant project practices change.
