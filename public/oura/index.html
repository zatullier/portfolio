Zach’s Oura Data Export

A personal-use project to download and analyze the account owner’s Oura data through the Oura API.

Purpose and status

The planned downloader runs on the owner’s computer and exports available Oura records for personal backup and analysis. It is under development and is not a public service. This website provides project information only; it does not connect to Oura or collect health data.

Account access

The downloader will request the owner’s permission through Oura’s authorization process. Available records depend on the granted permissions and Oura’s API. The project is independent and is not affiliated with or endorsed by Oura.

Contact

Maintainer: Zachary Tullier. For project questions, use the GitHub issue tracker. Do not post health data, passwords, tokens, or other private information.
